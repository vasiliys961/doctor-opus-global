## Main platform inheritance audit (verified Git blob SHA against `main`)

The following **already exist unchanged in the contest branch**, so copying them again is unnecessary:
- `lib/prompts.ts`: medical modality descriptions including ECG, CT, MRI, X-ray, dermatoscopy, ultrasound; separates visual observations from clinical inferences.
- `lib/diagnostic-report.ts`: clinical/radiology/ECG report structure, Findings vs Impression, report validation.
- `lib/chat-triage.ts`: complexity-aware routing useful for selective Opus/Gemini Pro escalations.
- `lib/diagnostics/orchestrator.ts`: mother clinical specialists, debate, disagreement and final synthesis. The experiment has a separate contest-only orchestrator; avoid wholesale replacement.
- `lib/openrouter.ts` **differs** on contest vs parent. Never overwrite wholesale. Import/factor only reviewed functions.
- Prior experiment: targeted FDA and NIH evidence retrieval showed an exploratory positive signal; cases too few to promote global RAG.

## External borrowable features (ideas, not proprietary code)
1. Doximity-style **evidence retrieval and reranking**: prioritize safety-critical prescribing labels (FDA/EMA), up-to-date society guidelines, dates and citation anchoring. Use structured drug checks before high-risk management.
2. MedAgentBench/PhysicianBench **typed FHIR tools and evaluators**: schema-validate every tool action; separate read/mutate permissions, idempotent ServiceRequest creation; deterministic note/document save after evidence retrieval (discovered in real pilot).
3. **Independent visual read**: model Flash observes pixels without first seeing another model's diagnosis; Pro used for ambiguity, important red flags or confirmed disagreements. Track miss/extra finding independently from report text similarity.
4. **Cost-aware model routing**: fast SCT model, Sonnet by default for simpler agentic and diagnoses, Opus for unresolved complex/high-risk cases; empirical Opus on one synthetic CPC case cost more without confirmed accuracy benefit.

## No registration / freely licensed substitute sources
- **NOHARM/SCT:** [ARISE Network MAST open benchmarks](https://github.com/ARISENetwork/mast) (honor source license; original MAST private test set excluded).
- **CPC-like:** [Microsoft SDBench synthetic cases](https://github.com/microsoft/sdbench) for functional testing; [MultiCaRe](https://pmc.ncbi.nlm.nih.gov/articles/PMC10792687/) contains >96,000 CC BY open-case clinical examples, article/image-specific source license still needs confirmation. Do not claim actual NEJM CPC-Bench from substitutes.
- **Radiology:** [ReXrank IU-Xray public metadata](https://github.com/rajpurkarlab/ReXrank), original Indiana Open-i pixels via `dz-osamu/IU-Xray` research dataset. Original test metadata and images, but no claim of private leaderboard.
- **Derm:** [ISIC archive](https://www.isic-archive.com/blank-1) — select individual **CC0** or **CC BY** images and pathology labels with attribution as required; our original two Wikimedia CC BY-SA images are usable for research smoke. Do not extract gated Stanford DDI without registration.
- **Agentic:** [MedAgentBench v2 public code and disposable FHIR Docker](https://github.com/ericoericochen/medagentbenchv2); Stanford [PhysicianBench public task instructions](https://github.com/HealthRex/PhysicianBench). The latter's real EHR image is available separately via [Stanford Redivis](https://stanford.redivis.com/datasets/a0ek-0ad8tjsw9); our substitute is FICTIONAL.
- No copyrighted textbook chapters, private medical records, restricted DDI files or real physician data have been added to the public repo.
